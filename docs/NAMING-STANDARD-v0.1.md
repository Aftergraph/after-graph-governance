# NAMING STANDARD — ABDE ecosystem

> Canonical naming conventions. Part of the ABDE Brand Architecture v0.2 (provisional).

| Layer | Name |
|---|---|
| ORGANIZATION | ABDE Intelligence |
| PRODUCT | ABDE Platform |
| RESEARCH ORGANIZATION | ABDE Research |
| TECHNICAL SYSTEMS | Trust Gateway, WORKS |
| STANDARDS | AIE, SPEC-* |
| RESEARCH INITIATIVES | After Graph, MISSION-Bench |
| STUDIES | STUDY-### |

## RULE: Do not prefix every subsystem with ABDE.

Avoid: "ABDE Trust Gateway", "ABDE WORKS", "ABDE AIE" — unless a future legal/product requirement specifically demands it.

Rationale:
1. Technical systems already carry unambiguous, established names.
2. Standards (AIE) must stay vendor-neutral; an umbrella prefix signals ownership that contradicts AIE's independence.
3. Research initiatives keep their narrative identity (After Graph) separate from any company brand.
4. Fewer prefixed names survive a final brand change: if ABDE is replaced, only ORGANIZATION/PRODUCT/RESEARCH names change.
